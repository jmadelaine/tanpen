# Frontend Development

We use **React** with [Vite][vite-docs] for the front end.  
The back end is handled by Supabase (see [(./BACKEND.md)][(./BACKEND.md)]).

---

## Prerequisites

- [Node.js][node-js]

Recommended VS Code extensions:

- `dbaeumer.vscode-eslint`
- `esbenp.prettier-vscode`

---

## Installation

Install dependencies with **npm**:

```bash
npm i
```

---

## Development

1. Start the local BE (see [BACKEND.md](./BACKEND.md#local-development)).
2. Start the app with `npm run dev`.
