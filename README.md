# Tanpen 短編

Tanpen is a web app for reading and sharing short Japanese stories. Users can
publish simple posts or short fiction, read stories from other writers, comment
on them, and rate them with a thumbs up or thumbs down.

The app is built with React, Vite, Tailwind CSS, TanStack Router, and TanStack
Query. The backend uses Supabase Edge Functions as the API layer and database.
